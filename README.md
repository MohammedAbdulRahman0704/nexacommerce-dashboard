# NexaCommerce Analytics Dashboard

A data analytics dashboard built using HTML, CSS, JavaScript, and Chart.js.

## Features
- Revenue trends & forecasting
- Cohort retention analysis
- Churn & funnel insights
- Product performance tracking
- Business impact insights

## Tech Stack
- HTML, CSS, JavaScript
- Chart.js

## Dataset
Simulated e-commerce dataset (2022–2024)
